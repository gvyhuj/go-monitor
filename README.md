# 도레미 — 주가 감시 사이트

https://gvyhuj.github.io/go-monitor/

한 종목의 주가가 **급등·급락**한 순간을 자동으로 기록하고, 왜 움직였는지를 찾아 웹사이트로 보여줍니다.
회사가 낸 보도자료나 외부 기사가 실제로 주가에 영향을 줬는지도 함께 계산합니다.

- 서버나 PC 없이 GitHub에서 자동으로 돌아갑니다. 비용 0원.
- 분석 자료는 모두 암호화되어 있어, 사이트에 들어가야만 볼 수 있습니다.

```
GitHub Actions (장중 약 3분마다, 그 밖에는 약 15분마다)            GitHub Pages
  시세·뉴스 수집 → 급등·급락 감지 → 원인 분석 → 알림  ──▶  사이트 (자료는 암호화)
  기록은 암호화해서 다음 실행으로 넘김
```

## 무엇을 기록하나
| 단계 | 기준 | 알림 |
|---|---|---|
| 대형 | ±10% 이상 | 보냄 |
| 급등·급락 | ±5% 이상 | 보냄 |
| 관찰 | ±3~5% | 사이트에 기록만 |

- 하루 기준: 종가가 전일 종가보다 위 기준 이상 움직인 날
- 장중 기준: 30분 안에 위 기준 이상 움직이고, 그 가격이 5분 이상 유지되고, 그 구간 거래대금이 5천만 원 이상
  (체결 한두 건으로 튄 가격은 제외)

## 원인을 찾는 방법 (실무 3단계)
1. **① 몫 나누기**: 실제 등락 = 시장(KOSDAQ) 몫 + 업종 몫(업종 ETF) + 종목 고유 몫.
   고유 몫이 평소의 2배 이상이면 '회사만의 이유가 있는 움직임'으로 봅니다.
2. **② 기사 직후 검증**: 기사가 나온 직후 30분(장 마감 뒤면 다음 날 시초가) 움직임이
   평소 같은 길이 구간 100번 중 5번 미만으로 드문 크기면 '기사 효과 있음'. 보도자료 효과 측정도 이것으로 합니다.
3. **③ 수급**: 거래량이 평소의 몇 배인지, 같은 증권사 창구가 업종 종목을 묶어 샀는지, 외국인·기관 순매수.

판단 순서
- 바깥 몫(시장·업종)이 절반 이상 → 시장·업종 흐름 (그 흐름을 만든 묶음 매수·업종 이슈를 함께 표시)
- 고유 몫이 이례적이고 기사가 ②를 통과 → 그 기사
- 기사 없이 수급만 뚜렷 → 수급
- 아무것도 아니면 → '원인 미확인'

업종이 움직인 배경(국제 정세, 미국 국방 정책, 수출 이슈 등)은 움직임 전에 나온 기사와
그날 업종 시황 기사로 찾아 '왜 샀을까(추정)'로 보여줍니다.
종목토론방 글 급증, 짧은 시간 큰 주문, 회사 일정은 참고로만 보여줍니다.

## 자료 출처
- 시세·거래원·투자자별 매매·종목 뉴스: 네이버 증권 공개 화면 데이터
- 국제·정치·업종 이슈 기사: 구글 뉴스 (한국 언론 + 영어권 주요 언론만).
  같은 내용의 한국어 기사가 있으면 영어 기사 대신 한국어 기사를 보여줍니다.

## 알림
급등·급락(±5% 이상)이 생기면 GitHub 휴대폰 앱으로 푸시 알림이 옵니다.
알림에는 시세 변동만 적히고, 원인은 사이트에서 확인합니다.

## 사이트에서 하는 일
- 기사 직접 등록·목록에서 빼기: 버튼을 누르면 GitHub 요청 화면이 열리고, [Create]를 누르면 몇 분 안에 반영됩니다.
  요청 내용은 암호화되어 있어 다른 사람은 알아볼 수 없습니다.

## 알아두실 점
- 원인 분석은 시간상·시장상 연관성에 근거한 추정입니다. "이 때문에 올랐다"는 확정이 아닙니다.
- 공개 자료의 형식이 바뀌면 일부 수집이 멈출 수 있습니다. 실행 화면의 점검 표시로 확인합니다.
