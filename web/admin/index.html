관리자 전용

일반 사이트와 다른 관리자 비밀번호를 입력하세요. 이력은 이 비밀번호로 별도 암호화되어 있습니다.

일반 사이트 비밀번호와 다릅니다. 브라우저가 비밀번호를 자동으로 채웠다면 지우고 관리자 비밀번호를 직접 입력하세요.

비밀번호와 열쇠는 이 브라우저에 저장하지 않습니다. 새로고침하거나 15분 동안 사용하지 않으면 다시 입력해야 합니다.

계산식 검증용 데이터

기사·공시 전체 분석값, 일별·보유 분봉 시세, 비교 종목, 기사 원본과 계산 기준을 하나의 JSON으로 내려받습니다. 관리자 비밀번호로 암호화된 자료를 이 브라우저에서만 복호화합니다.

다운로드 파일은 암호화되지 않은 원본 데이터입니다. 업무용 PC에 보관하고 외부에 공개하지 마세요. 비밀번호·API 키 등은 포함하지 않습니다.

일반 페이지에는 최신 분석만 표시됩니다. 여기에는 보관을 시작한 이후의 변경된 결과가 남습니다. 과거 전체 이력이 복구되는 것은 아닙니다.
